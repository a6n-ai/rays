---
title: "Download from S3 buckets on Mac"
description: "Browse and download from Amazon S3, Cloudflare R2, Backblaze B2, Wasabi, MinIO and any S3-compatible bucket with Rays, dl and MCP. Secret keys stay in your Keychain."
---

Rays can browse an S3-compatible bucket and download objects from it. Bucket downloads use the same [engine](/docs/engine/) as web links: parts, resume and the adaptive connection count all work the same way.

## Add a bucket

Click **Cloud** in the sidebar, open **Buckets** at the top, pick your provider, and fill in the bucket name, your keys, and anything the provider needs, such as a region or an R2 account ID. Rays fills in the endpoint for you, and every field stays editable. **Generic S3** takes any endpoint URL.

### From the AWS CLI or Cloudflare

If the `aws` command is set up on your Mac, **Buckets** lists each profile's buckets with an **Add** button. Rays asks `aws` for keys each time, so saved keys, `aws login` and SSO sessions all work, and Rays stores no secret for these buckets. Rays only lists buckets and reads files.

If the `cf` command is logged in to Cloudflare, **Buckets** lists your R2 buckets. The first **Add** creates one read-only R2 token named "Rays (read-only R2)" in your account and keeps its key in your Keychain.

From Terminal: `dl bucket add media --provider aws --region ap-south-1 --aws-profile default`.

### By hand

When you click **Add Bucket**, Rays lists the bucket once to check the keys. Wrong keys show the provider's error, such as `AccessDenied`, and nothing is saved. The keys need permission to list the bucket and read objects.

| Provider | What you enter |
|---|---|
| Amazon S3 | region, for example `us-east-1` |
| Cloudflare R2 | account ID |
| Backblaze B2 | region, for example `us-west-004` |
| Wasabi | region |
| DigitalOcean Spaces | region, for example `nyc3` |
| Google Cloud Storage | HMAC keys only |
| Hetzner Object Storage | region: `fsn1`, `nbg1` or `hel1` |
| Akamai / Linode | region |
| Scaleway | region, for example `fr-par` |
| OVHcloud | region |
| Oracle Cloud | region and namespace |
| Alibaba Cloud OSS | region |
| Supabase Storage | project ref and region |
| Tigris | nothing extra |
| MinIO / self-hosted | endpoint URL |
| Generic S3 | endpoint URL, region, addressing style |

Azure Blob Storage is not S3-compatible. A shared access signature (SAS) link to an Azure file downloads in Rays as a normal web link.

## Browse and download

Open **Browse** at the top of the Cloud page. With more than one bucket, pick one with the cloud button. Click a folder to open it, the back arrow to go up, and the download button next to a file to add it to your downloads. **Cloud downloads** lists everything downloaded from your buckets. Large folders load 1,000 items at a time; click **Load More** for the rest.

You can also paste or drop an `s3://bucket/key` link, the same way as a web link.

## Where your keys are kept

The secret access key is saved in your Mac's Keychain, never in Rays' database, logs or settings. Each request to the bucket is signed just before it is sent, with a link that expires after an hour. A long download or a resume the next day still works.

Removing a bucket deletes its secret from the Keychain.

## From Terminal

```sh
dl bucket providers
dl bucket add media --provider r2 --account-id YOUR_ACCOUNT_ID --key-id YOUR_KEY_ID
dl bucket list
dl ls s3://media/photos/
dl s3://media/photos/beach.jpg
dl bucket remove media
```

`dl bucket add` asks for the secret key without showing it. In a script, pipe it in so it stays out of your shell history:

```sh
security find-generic-password -s my-r2 -w | dl bucket add media --provider r2 --account-id YOUR_ACCOUNT_ID --key-id YOUR_KEY_ID
```

For an S3 server without a preset, pass `--endpoint URL`, plus `--region` and `--path-style` if it needs them. See [the dl command](/docs/dl/#s3-buckets) for every option.

## From AI assistants

The [MCP server](/docs/mcp/) has `list_buckets` and `browse_bucket`, and `add_downloads` takes `s3://` links. An assistant cannot add a bucket, so your keys never pass through it.
