The extension adds **Download with Rays** to the menu when you right-click a link. It talks to Rays through a small helper that Rays installs for each browser. It's free, collects no data, and sends links only to Rays on your Mac.

<BrowserCards />

## Add it

1. Open **Browsers** in the Rays sidebar. Rays lists the browsers it found.
2. Click **Install All Helpers**, or install the helper for one browser.
3. Click **Get Extension** next to your browser, or pick your browser above, then add it from the store.
4. The browser's row on the Browsers page shows **Connected to Rays**.

Rays lists every browser on your Mac. A browser built on Chromium or Firefox that Rays doesn't know by name gets the same rows when Rays finds its data folder. Other browsers get a row that says why they aren't supported. Search, which runs Chrome Web Store extensions, is supported.

Brave reads its helper from Chrome's folder, so **Install Helper** writes it there for every Chromium browser. You don't need Chrome, and Brave and Chrome share one helper. Where macOS keeps a browser's files private, as with Brave, the row shows **Extension added** once you have clicked the Rays button in that browser once.

## Use it

- Right-click a link and choose **Download with Rays**. The toolbar badge shows `+N` when Rays accepted it and `!` on an error.
- Click the Rays button in the browser toolbar to open the popup. It shows **Connected to Rays** and how many downloads are running, a box to paste a link with **Download**, the **Send all browser downloads to Rays** switch, the extension version and **Check for updates**. If the helper is missing, it shows **Install helper**, which opens Rays to install helpers, and **Get Rays**.
- **Send all browser downloads to Rays** hands every browser download to Rays. The browser's own copy is cancelled only after Rays accepts the link. In Search this doesn't work yet, because Search doesn't tell extensions when a download starts. Use right-click, the popup's paste box, or copy the link.
- The extension updates itself as soon as the store has a new version.

## Remove it

Remove the extension in the browser, then click **Remove helper** for that browser on the **Browsers** page, or **Remove all helpers**.
